# Prism-Insurance-Dashboard

1. Project Title / Headline

Prism Insurance Dashboard – Insurance Data Analysis Dashboard

2. Short Description / Purpose

The Prism Insurance Report is a Power BI dashboard project designed to analyze and visualize insurance-related data. It provides an interactive view of key insurance metrics, helping users understand premium amounts, coverage amounts, and other relevant business insights through data visualization.

The main purpose of this project is to demonstrate the use of Power BI for transforming insurance data into meaningful visual insights that support data analysis and decision-making.

3. Tech Stack

Microsoft Power BI – Dashboard development and data visualization
Power Query – Data cleaning and transformation
DAX – Calculations and measures
Word Cloud Visual – Visual representation of text-based data

4. Data Source

Source: Udemy
The project is based on an insurance analytics learning project.
The data is used to explore insurance metrics and create interactive visualizations.

5. Features / Highlights

Interactive Power BI dashboard for insurance data analysis
Visualization of key metrics such as Premium Amount and Coverage Amount
Clear and user-friendly dashboard layout
Data visualization to support business insights
Word Cloud visual for exploring text-based information
Power BI template (`.pbit`) for reuse and customization
Practical demonstration of business intelligence and data analytics skills

Project File

`Prism Insurance Report.pbit` – Power BI report template

Tools Used

Microsoft Power BI | Power Query | DAX
